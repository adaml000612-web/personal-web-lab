# CET-6 425+ 手机每日打卡

把 2026 年 12 月 CET-6 备考计划做成适合手机的轻量打卡工具。打开后直接显示当天任务，完成一项勾一项，不需要再打开 Excel 找日期或手动保存。

## 使用方式

- “今天”：查看当天任务、逐项勾选或一键完成；实际用时和一句话备注均为选填。
- “日历”：快速查看已完成、部分完成、未开始和休息日，也可点日期回看任务。
- “进度”：查看学习日、任务数、预计投入时长和听力/阅读/写译等模块进度。
- “设置”：导出或恢复 JSON 备份，换手机前可手动迁移记录。

勾选、用时和备注会自动保存在当前浏览器中，不需要账号，也不会上传学习记录。清理浏览器数据会删除本机记录，因此建议定期导出备份。

## 安装到手机主屏幕

项目部署到 HTTPS 站点后可作为 PWA 安装：

- iPhone/iPad：用 Safari 打开，点“分享”→“添加到主屏幕”。
- Android：用 Chrome 打开，在页面设置中点“安装到主屏幕”；也可以从浏览器菜单选择“安装应用”。

首次联网打开并完成离线缓存后，即使暂时没有网络，也能继续查看计划和打卡。

## 本地运行

Service Worker 需要 HTTP(S) 环境；不要直接双击 `index.html`。在本目录启动任意静态服务器，例如：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4173/>。
