# 宿舍桌面布局规划

一个可直接离线打开的单文件宿舍桌面规划页，以 120 × 60 cm 上床下桌为基准，展示黑白灰简约桌搭的俯视布局。

## 页面内容

- 90 × 60 cm 洞洞板垂直收纳区
- 24 寸显示器与机械臂主工作区
- 笔记本副屏、平板信息屏和桌面充电区
- 无线键鼠主操作区
- 桌下电源、插排与理线建议
- 完整标注 / 清爽预览切换，以及打印或保存 PDF

## 本地预览

直接用浏览器打开 `index.html` 即可。页面不依赖外部字体、图片、脚本、框架或网络连接。
