# AI / Agent 实习强化计划打卡页

一个无需安装、无需联网、可直接双击打开的单文件学习打卡工具。

## 使用方式

打开 `ai-internship-6week-tracker.html` 即可使用。打卡状态、学习时长和每日备注保存在当前浏览器的 `localStorage` 中。

## 计划范围

- W1：Python 基础
- W2：Git / pytest / API
- W3：LLM API + FastAPI
- W4：RAG
- W5：Agent + 重写 Bug Fixing Agent
- W6：简历 / 面试 / 投递

2026 年 9 月 30 日至 10 月 5 日为旅行暂停期，不计正式学习日；计划于 11 月 4 日结束。

## 数据说明

数据只保存在打开页面的浏览器和设备中。清除浏览器站点数据或点击页面中的“重置数据”会移除记录。
