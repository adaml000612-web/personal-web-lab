# 2026 年 12 月 CET-6 425+ 备考计划

一份从 2026 年 9 月 7 日开始、按约 450 分能力构建容错的 CET-6 每日备考计划。计划以听力和阅读为提分核心，写作与翻译维持并小幅提升。

## 适用背景

- CET-6 当前成绩：281 分
- 听力：78 分
- 阅读：86 分
- 写作和翻译：117 分
- CET-4：429 分
- 工作日投入：90–120 分钟
- 周末投入：150–180 分钟

仓库没有保存原始成绩截图、证件号、准考证号或其他个人识别信息。

## 文件

- [`outputs/2026年12月CET-6备考计划_初版_v1.xlsx`](outputs/2026年12月CET-6备考计划_初版_v1.xlsx)：可修改、可打卡的 Excel，共 8 个工作表。
- [`outputs/2026年12月CET-6备考计划_初版_v1.pdf`](outputs/2026年12月CET-6备考计划_初版_v1.pdf)：20 页便携阅读版，每周一页每日计划。
- [`src/build_cet6_plan.py`](src/build_cet6_plan.py)：生成及验证 Excel/PDF 的源代码。

## 计划特征

- 覆盖 2026-09-07 至暂定 2026-12-12，共 97 个自然日、92 个学习日，计划约 177.2 小时。
- 2026-09-25 中秋节只安排 35 分钟轻量任务。
- 2026-09-30 至 10-01 仅保留少量词汇；10-02 至 10-05 完全留空且不形成欠账。
- 莆田学院校历中的运动会为 2026-11-12 至 11-14，三天只安排 15–20 分钟词汇。
- 真题按 `F0`、`D01–D05`、`M01–M06` 编号，避免依赖不同出版社的页码和套次排序。
- Excel 包含总览、每日计划、资料清单、真题映射、每周复盘、模考记录、错题记录和使用说明。

## 重新生成

已在 Windows 11、Python 3.12 环境验证。PDF 使用系统自带的微软雅黑字体。

```powershell
python -m pip install -r requirements.txt
python src/build_cet6_plan.py
```

脚本会在项目根目录的 `outputs/` 中重新生成 Excel 和 PDF，并检查特殊日期、工作表结构和 PDF 页数。

## 验证结果

- Excel 可由桌面版 Microsoft Excel 打开，公式、表格筛选和数据验证有效。
- PDF 共 20 页，已渲染抽查封面、资源页、旅行周、运动会周和冲刺周。
- 10-02 至 10-05 的计划分钟数均为 0。
- 11-12 至 11-14 均只包含词汇维护任务。
