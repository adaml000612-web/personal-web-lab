# Stock 101

面向完全零基础用户的关卡式股票学习与模拟训练工具。项目不预测股票、不推荐个股，V1 不接入真实股票 API，也不包含用户系统或 AI 功能。

## 当前进度

第三阶段已完成两个连续学习闭环：第一关讲解股票所有权，第二关讲解价格、预期和买卖双方。两关均包含教学、案例、互动反馈和总结，现已支持单选题、判断题、错题重试、正确答案解析、关卡内步骤恢复和统一答题记录。

尚未实现第三关以后内容、模拟 K 线和模拟股票训练。

## 本地预览

直接用浏览器打开 `index.html`，或在本目录启动静态文件服务器。课程数据位于 `content.js`，交互逻辑位于 `app.js`。
