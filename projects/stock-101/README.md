# Stock 101

面向完全零基础用户的关卡式股票学习与模拟训练工具。项目不预测股票、不推荐个股，V1 不接入真实股票 API，也不包含用户系统或 AI 功能。

## 当前进度

第二阶段已完成首个完整学习闭环：可从关卡地图进入第一关，完成知识教学、案例、单选题、错误重试、正确答案解析和关卡总结；完成后会保存进度并解锁第二关。支持刷新后恢复进度及确认后重置。

尚未实现第二关以后内容、判断题、模拟 K 线和模拟股票训练。
