# Stock 101

面向完全零基础用户的关卡式股票学习与模拟训练工具。项目不预测股票、不推荐个股，V1 不接入真实股票 API，也不包含用户系统或 AI 功能。

## 当前进度

当前已进入真实用户测试版：只展示实际可用的三个互动关卡，首次用户可直接开始，回访用户可继续上次步骤；完成每关会说明已经掌握的能力，完成三关后显示明确的测试版成果。

K 线、模拟市场、第四关以后内容、AI、真实行情和用户系统均不在当前测试范围内。

## 本地预览

直接用浏览器打开 `index.html`，或在本目录启动静态文件服务器。课程数据位于 `content.js`，交互逻辑位于 `app.js`。
