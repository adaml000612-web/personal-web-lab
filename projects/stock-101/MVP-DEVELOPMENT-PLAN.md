# Stock 101 MVP 开发计划

## 产品定位

Stock 101 不是普通课程网站，而是面向完全零基础用户的股票学习与训练工具。用户通过关卡学习概念，在虚构市场中完成判断和操作训练，再通过即时反馈纠正误区。

产品只用于教育，不预测股票、不推荐个股，也不接入真实股票行情。

## MVP 核心闭环

进入训练营 → 按顺序解锁关卡 → 学习一个概念 → 完成答题 → 获得针对性反馈 → 在模拟市场中应用 → 保存进度 → 解锁下一关

## V1 功能

### 1. 关卡式学习路径

- 6 个由浅入深的固定关卡
- 完成当前关后解锁下一关
- 显示未开始、进行中、已完成和锁定状态
- 浏览器本地保存进度，无需注册
- 支持清除进度并重新训练

### 2. 课程训练

- 每关围绕一个明确学习目标
- 内容由概念卡、生活化示例、误区提示和小结组成
- 每关包含 2～3 道单选、判断或情境题
- 正确后解释原因，错误后指出误区并允许重试

### 3. 模拟股票训练

- 全部使用虚构公司、虚拟资金和预设事件
- 用户在训练场景中观察、判断或执行模拟操作
- 不做收益排行，不鼓励高频交易
- V1 包含“价格变化判断”和“分散风险”两个训练场景

### 4. 模拟 K 线

- 使用本地固定数据，不调用真实股票 API
- 展示开盘、最高、最低、收盘和成交量
- 支持悬停或点击查看单根 K 线数据
- 支持“识别上涨/下跌”“比较波动”“事件后观察”训练
- 不加入技术指标、买卖信号或未来走势预测

### 5. 答题反馈

- 提交后立即显示结果
- 反馈包含结果、原因、对应知识点和下一步动作
- 错误答案记录到本地，供本关重试
- 完成关卡后显示掌握情况，不只显示分数

### 6. 基础页面

- 首页/训练营入口
- 学习路径页
- 关卡训练页
- 模拟市场页
- 术语页
- 教育用途说明

## V1 不做

- AI 学习助手
- 真实股票 API 与实时/延迟行情
- 真实公司或个股分析
- K 线技术指标和交易信号
- 注册、登录和多设备同步
- 证券账户连接
- 完整模拟交易所、订单簿或撮合系统
- 排行榜、社区、支付和会员
- 内容管理后台

## 未来版本

### V1.1

- 错题复习中心、更多训练场景
- 前测、后测和知识点掌握度
- 每日挑战和学习连续记录
- 课程内容版本管理

### V2

- 用户系统与跨设备同步
- 个性化复习路径
- 指数、基金、ETF 和财务报表课程
- 教学内容管理后台
- 经评估后再规划受控 AI 辅导

### V3

- 有明确教学价值时接入合规的延迟行情
- 使用真实历史数据进行案例教学
- 仍不提供荐股、预测和买卖信号

## 10 个工作日开发顺序

1. 范围冻结、项目骨架、首页和 6 关数据结构
2. 关卡地图、顺序解锁、本地进度和移动端布局
3. 内容卡、步骤导航、三类题型和第一关内容
4. 即时反馈、错题记录、完成关卡和其余核心题目
5. 本地 OHLCV 数据、模拟 K 线、成交量和数据详情
6. K 线上涨/下跌、振幅与事件观察训练
7. 虚构公司、预设事件和分散风险模拟训练
8. 全流程整合、术语页、内容与风险表述审核
9. 移动端、键盘、异常状态和零基础用户试用
10. 最终验证、README、上传 GitHub 和线上发布

## 第一阶段交付范围

第一阶段覆盖第 1 天任务：项目结构、设计系统、首页、关卡地图首屏、6 关数据定义，以及本地进度的数据接口。暂不实现正式课程内容、答题引擎、K 线图和模拟交易逻辑。
